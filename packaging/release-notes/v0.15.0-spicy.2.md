**Spotifast Spicy Lyrics** 0.15.0-spicy.2 is an unofficial fork of [Spotifast](https://github.com/crmne/spotifast) 0.15.0. It adds four romaji display modes, a right-aligned second singer and background vocal lines. The word-by-word karaoke lyrics stay the same.

![The full screen lyrics view fills the active line word by word](https://raw.githubusercontent.com/TheBestIT/spotifast-spicylyrics/main/docs/spicy/demo.gif)

## New

- **Choose how romaji and kanji show.** The **Romaji** button in the lyrics header opens a menu with four modes: romaji on top, kanji on top, kanji only and romaji only. Settings has the same menu in "Romaji for Japanese lyrics". The kanji and the romaji fill at the same time.
- **A setting from an earlier version keeps its romaji.** A setting with romaji on loads as romaji only.
- **The second singer sits on the right.** In a duet, the lines of the second singer align to the right. Background vocals show as a smaller italic line under the main line.
- **Demo mode shows more views.** Demo mode adds surfaces for each romaji mode and for a duet (`duet` and `duet-panel`).
- **The fork has an agent guide.** The repository has `docs/spicy/CONTEXT.md`, a guide for coding agents. It also has `scripts/capture-readme-media.ps1`, which captures the README images.

## Install

- **Windows:** download `…-x86_64-pc-windows-msvc-setup.exe` and open it.
- **Linux:** download the `.AppImage`, the `.deb` (Debian 13, Ubuntu 24.04 and newer), the `.rpm` (Fedora) or the `.flatpak`.

This release replaces an installed Spotifast or Spotifast Spicy Lyrics and keeps its settings and sign-in. Read the [README](https://github.com/TheBestIT/spotifast-spicylyrics#readme) for the Spicy Lyrics setup, the services that the app contacts, and the build steps.
